# ExoBrain 项目导览：公开演示资料

《ExoBrain 项目导览》是一份用于体验知识检索的自写说明，核对日期为 2026 年 10 月 14 日。内容来自项目源码及公开技术文档，不包含人员信息、私人对话或运行环境配置。本文中的“已实现”表示源码中已有对应逻辑，实际在线效果仍需通过部署测试确认。

## ExoBrain 技术栈：Java、Spring Boot、Spring AI、React 与数据库

《ExoBrain 项目导览》：ExoBrain 是基于 Java 的 AI Agent 项目，源码中仍使用 JChatMind 作为部分模块和类名。当前部署使用 Java 21，Spring Boot 版本为 3.5.8，Spring AI 版本为 1.1.0；前端采用 React 19。MyBatis 负责数据库访问，PostgreSQL 保存业务数据，pgvector 扩展提供向量检索。可以把前端理解为接待窗口，把后端理解为协调业务的工作人员，把数据库理解为可持续保存记录的资料柜。

源码依据：项目部署说明、部署 Dockerfile、pom.xml、前端 package.json。基础概念来源：[Spring Boot 3.5 系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)。框架最低要求与具体项目的运行版本应分别理解；本项目采用的 Java 版本以部署说明为准。

## ExoBrain Agent 如何决策、调用工具并结束任务

《ExoBrain 项目导览》：Agent 的核心流程是“判断下一步—执行工具—读取工具结果—继续判断”。例如，需要项目资料时可以调用 KnowledgeTool 检索知识库，然后依据返回片段组织回答。模型提出工具调用，Java 程序负责实际执行和回填结果。系统关闭框架的内部自动工具执行，由自己的循环管理中间步骤。一次运行最多执行 20 轮步骤，以限制无休止循环；模型交付答案后可自然结束，也可使用终止工具。源码还包含缺少用户答复时的补充收尾检查，但这不代表每次回答都一定正确。

源码依据：JChatMind.java、KnowledgeTools.java。

## ExoBrain Agent 配置、知识库与会话历史分别保存什么

《ExoBrain 项目导览》：Agent 配置包括系统提示词、模型标识、可选工具列表和关联知识库列表。运行时工厂会读取这些配置、装配工具，并从数据库恢复近期会话消息，供后续回答使用。数据库基础结构分为六类表：Agent、会话、消息、知识库、文档、文档片段。知识库保存可检索资料，会话历史保存交互过程，两者承担不同职责。保存聊天记录不会自动把聊天内容加入知识库，也不等于重新训练模型。

源码依据：JChatMindFactory.java、ChatMessageFacadeServiceImpl.java、数据库建表脚本。

## ExoBrain 已实现的功能与尚待改进的方向

《ExoBrain 项目导览》：源码已实现 Agent 循环、工具装配、会话消息持久化、Markdown 文档索引和向量检索，并使用 SSE 向页面发送执行状态及回答。可继续研究的方向包括其他文档格式的解析、正文级分段索引、检索结果的结构化来源标记，以及自动切换备用模型。这些方向不能当作当前已交付能力；项目 README 明确说明自动切换备用模型尚未完成。现有代码会对识别出的模型繁忙提示有限重试，有限重试与自动更换模型是两种不同机制。

源码依据：项目 README、JChatMind.java、DocumentFacadeServiceImpl.java、RagServiceImpl.java。

## HR 如何使用 ExoBrain 公开资料进行体验

《ExoBrain 项目导览》：建议从“项目解决什么问题”“资料如何被检索”“哪些能力还没实现”三类问题开始，再核对答案是否符合文档。判断依据是回答内容与检索证据，不应仅凭术语数量或回答长度。本文没有提供商业客户数量、准确率、性能排名或招聘效果数据，也没有真实候选人资料；因此不能从本文推导这些成绩。演示问题用于理解技术与验证检索，不用于对真实人员作录用决定。

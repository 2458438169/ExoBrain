# 架构决策记录（ADR）索引

本目录保存需要长期保留理由的设计决策：每个 ADR 写明**问题、考虑过的方案、最终选择、代价、验证方式与何时重新评估**。ADR 描述决策与边界，不代替代码、契约或交付记录。

编号与负责它的开发任务对应（例如 `0003` 由任务 03 提供），文件名使用 `NNNN-短标题.md`。

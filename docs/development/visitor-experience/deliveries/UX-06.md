## 独立发现并修复的问题

| 范围 | 问题 | 最终行为与证据 |
| --- | --- | --- |
| 活动运行与 SSE | 断线可能提前结束等待；终态漏送后卡住；旧 AI_DONE 影响下一轮 | 断线保留活动运行；重连/可见性恢复及 3 s 轮询核对服务器；EventSource 关闭后有界退避重建；按 runId 过滤，AI_DONE 仅触发核对 |
| 提交意图 | 受理旧请求时清空了新编辑的草稿 | 受理只清理对应意图；首响应丢失重试仍同键/同运行，下一条草稿保留 |

| 运行读取 | 坏响应条目 `[null]` 可白屏，错误被解释成“未保存” | 校验信封、条目与 runId；明确 idle/loading/ready/error；后续失败保留已有正文并可重试 |
| 等待反馈 | 排队占位不会随着轮询进入 RUNNING；长等待无时间说明 | 展示实际状态/秒数；超过 10 s 解释等待，保留停止和草稿编辑 |
| 长答阅读 | 回答跳到末尾；已读内容/选择被新事件带走；代码溢出 | 布局完成后定位正文开头；阅读中保留位置并提示新回答；长代码在气泡内滚动，四宽度无横向溢出 |
| 来源焦点 | 快速关闭并打开另一来源时，旧延迟回焦抢焦点 | 新开来源取消旧回焦计时器；卸载清理；6 次真实来源切换复验 |
| 取消边界 | DemoException 没有保留 HTTP 权限语义；网关允许方法不完整 | 自有取消 POST；其他方法含 PROPFIND 在网关 405；跨游客 404、只读精选取消 403 |
| 网关发布 | 旧 map 可能重复、reload 失败缺少完整回退 | 幂等替换旧 map；候选/生效配置 nginx -t；reload 失败恢复旧字节并再次 reload |
| 资料与模型答复 | 旧资料缺重启语义/MIT；真实 Q05 混入工具参数残片 | 版本化 v2 补事实并重建候选索引；落库前拒绝观察到的协议残片，固定错误码、零正文，不伪造来源 |
